# Support Inquiry Draft — Automation Policy Clarification

**Status: DRAFT. Not sent. Requires Charlie's approval before sending.**

**To:** Eternal Cabal SEA support (via official Discord support ticket)
**From:** Charlie Labiogo
**Subject:** Request for written clarification on permitted accessibility / automation tools

---

Hello,

I am a player on the SEA server. I would like to request written clarification
on which accessibility or automation tools are permitted under the server rules,
so that I can stay within the rules while playing.

Specifically, I would like to know whether the following are allowed:

1. **External companion applications** that only read publicly available
   information from the official website (server status, announcements,
   download page) and do not interact with the game client in any way.

2. **Screen readers and text-to-speech tools** used to read in-game text for
   accessibility purposes.

3. **Operating-system level accessibility features** (Windows Narrator,
   high-contrast mode, sticky keys, mouse keys).

4. **Hardware with onboard macros** (keyboards/mice where a physical button
   replays a recorded keystroke sequence), and whether these are treated
   differently from software macros.

5. **Any software that reads or writes game memory, injects code, simulates
   input, or modifies the game client**, which I understand to be prohibited.
   I want to confirm my understanding is correct.

For clarity, I am **not** asking for permission to use bots, auto-combat,
auto-farming, or any gameplay automation. I am asking only whether the
specific categories above are permitted, so I can configure my setup
accordingingly and avoid any accidental violation.

If any of these require a specific disclosure or registration process, please
let me know what is needed.

Thank you for your time.

Charlie Labiogo
Eternal Cabal SEA

## Why this draft exists

The Night Shift companion was built with every in-game automation feature
disabled. This inquiry is prepared so Charlie can ask the administrators, in
writing, which accessibility tools are acceptable. Nothing is sent without
his explicit approval.
